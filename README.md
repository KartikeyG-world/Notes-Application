# Notes Application

A modern note management application built with **React**, **Redux Toolkit**, and **React Router** that enables users to create, manage, search, update, and organize notes through a clean and intuitive user interface.

This project demonstrates practical implementation of React state management, client-side routing, reusable components, and CRUD operations using a scalable frontend architecture.

---

# Features

* Create new notes
* View all saved notes
* Edit existing notes
* Delete notes
* Search notes instantly
* Copy note content with a single click
* Client-side routing for seamless navigation
* Responsive and user-friendly interface
* Global state management using Redux Toolkit
* Toast notifications for user actions
* Clean and modular component architecture

# Getting Started

## Clone the Repository

```bash
git clone https://github.com/KartikeyG-world/Notes-Application.git
```

## Navigate to the Project

```bash
cd Notes-Application
```

## Install Dependencies

```bash
npm install
```

## Start the Development Server

```bash
npm run dev
```

The application will be available on your local development server.
